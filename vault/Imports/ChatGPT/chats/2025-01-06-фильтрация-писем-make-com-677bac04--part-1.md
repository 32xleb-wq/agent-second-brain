    - Введите данные сервера (IMAP/POP), логин, пароль.
  - Укажите папку для обработки (например, "Входящие").
  - Настройте количество писем для обработки за раз (например, 10).
  
- **Gmail**:
  - Выберите **"Watch Emails"**.

  - Настройте доступ и выберите, какие письма обрабатывать.

---

## **ШАГ 2: Добавление фильтрации по ключевым словам**

1. Нажмите на линию после триггера и добавьте **"Фильтр"**.
2. Настройте **условия фильтрации**:
   - **Имя фильтра:** "Ключевые слова".
   - **Поле:** `Subject` (тема письма) или `Text` (тело письма).
   - **Оператор:** `contains` (содержит).
   - **Значение:** введите ключевые слова через запятую, например:
     ```plaintext
     срочно, запрос, ошибка
     ```

---

## **ШАГ 3: Действия при обнаружении ключевых слов**

### **1. Добавление перенаправления письма:**

1. Добавьте модуль **Email > Send an Email** (или **Gmail > Send an Email**).
2. Заполните поля:
   - **To:** Укажите адрес, на который необходимо переслать письмо.
   - **Subject:** Укажите тему письма или используйте переменную `{{Subject}}` для оригинальной темы.
   - **Body:** Укажите текст письма, например:
     ```plaintext
     Письмо перенаправлено на основании ключевых слов:
     {{Text}}.
     ```
   - Добавьте вложения, если необходимо (`Attachments`).

## **ШАГ 4: Действия при отсутствии ключевых слов**

2. В поле **Prompt** укажите текст для генерации:

3. Выберите модель, например, `gpt-4` или `gpt-3.5-turbo`.
4. Укажите длину ответа (например, 300 символов) и формат (`plain text`).

### **2. Добавление отправки ответа:**

1. Добавьте модуль **Email > Send an Email** или **Gmail > Send an Email**.
2. Заполните поля:
   - **To:** `{{From}}` (отправитель письма).
   - **Subject:** `RE: {{Subject}}` (ответ по теме письма).
   - **Body:** Укажите ответ из OpenAI:

     - **OpenAI (ChatGPT)** – создание ответа.

  - Вместо файла передается строка или другой тип данных.
