### Что именно считается «двойным кликом» на macOS  
На Mac бывает несколько жестов/настроек, которые пользователи называют «двойным кликом»:

| Ситуация | Как проявляется | Где отключить/подстроить |
|----------|-----------------|---------------------------|
| **Двойное-ТАП (tap-to-click)** на трекпаде вместо настоящего клика | Лёгкое постукивание пальцем запускает обычное «нажатие» | **Системные настройки → Трекпад → «Тапать для клика»** ← снимите переключатель |
| **Двойное-ТАП + перетаскивание** (Enable dragging) | Быстрый двукратный тап захватывает объект и тащит его без удержания кнопки | **System Settings → Accessibility → Pointer Control → Trackpad Options… → отключите «Enable dragging»** citeturn0search0turn0search4 |
| **Классический двойной-клик мышью** (открытие файлов, запуск) слишком чувствителен | Один щелчок часто воспринимается как два | **Accessibility → Pointer Control → Mouse & Trackpad → Double-click speed** — сдвиньте ползунок к «Slow» (чем медленнее, тем труднее случайно сдвоить нажатия) citeturn0search1turn0search5 |

## Пошагово (macOS Sonoma / Ventura)

1. **Отключить «двойной тап → перетягивание»**  
   *  > *System Settings*  
   * *Accessibility* → *Pointer Control*  
   * Нажмите **Trackpad Options…**  
   * Снимите галочку **Enable dragging** (или выберите «без drag lock», если нужно изменить вид жеста).

2. **Настроить чувствительность двойного клика для мыши и трекпада**

     * Сдвиньте к *Slow* — мак не засчитает два быстрых щелчка как двойной.  
     * Сдвиньте к *Fast* — наоборот, чтобы клик засчитался как двойной, придётся нажать очень быстро.

3. **(Необязательно) изменить порог через Terminal**  
   ```bash
   # увеличиваем интервал между кликами до 1,5 с
   defaults write -g com.apple.mouse.doubleClickThreshold -float 1.5
   ```
   Примените, затем выйдите из учётки или перезагрузитесь.

4. **Убрать «тап для клика» полностью** (если мешает)  
   * *System Settings* → *Trackpad* → «Tap to click» — отключите тумблер. citeturn0search7

### Если проблема остаётся
| Возможная причина | Что сделать |
|-------------------|-------------|
| **Аппаратный дребезг** кнопки мыши/трекпада | Проверить на другом устройстве; при дефекте — сервис или замена микропереключателя |
| **Периферия сторонних брендов** (Microsoft/Logitech) конфликтует с macOS 14 Sonoma | Поставить родной Magic Mouse / Trackpad или обновить драйвер-«Options» устройства citeturn0search9 |
| **Сторонние утилиты** (BetterTouchTool, USB Overdrive) меняют события кликов | Временно выгрузить их и проверить, исчезнут ли ложные двойные нажатия |

**Итого:**  
* Чтобы «двойной клик» ушёл со свайпов и перетаскиваний — выключаем *Enable dragging* в *Accessibility → Pointer Control → Trackpad Options*.  
* Чтобы macOS перестала принимать один щелчок за два — корректируем *Double-click speed* там же.  
* При оборудовании с износом — проверяем железо или используем утилиты-фиксаторы кликов.
