### 📦 Варианты реализации

#### 🔹 **Вариант 1: Ссылки в сообщении (простой)**
**Пример:**  
```text
Вот документы, которые помогут вам с регистрацией ООО:
📄 Устав — https://docs.google.com/document/d/xxx  
📄 Решение — https://docs.google.com/document/d/yyy  
📄 Договор — https://docs.google.com/document/d/zzz
```

**Как реализовать:**
1. В Google Drive создаёшь папку и кладёшь туда нужные файлы.
2. Делаешь их "доступными по ссылке".
3. В `Function Node` подставляешь шаблон с названиями и ссылками.
4. Через `Telegram -> Send Message` отправляешь пользователю этот текст.

✅ Преимущество: просто, быстро, не требует скачивания.  
✖ Недостаток: пользователь уходит в браузер.

---

#### 🔹 **Вариант 2: Скачивание файлов и отправка как вложения**
1. В Google Drive Node → `Search` по названию или по метке в `metadata`.
2. Получаешь `fileId` нужных 3–5 документов.
3. Используешь **Google Drive → Download File** (PDF или DOCX).
4. Скачанные файлы передаёшь в `Telegram Node -> Send Document` **один за другим** или в **Send Media Group (если это возможно)**.

⚙ Пример логики:
```text
User: пришли шаблоны для регистрации ИП

→ бот достаёт 3 Google Docs по теме
→ скачивает как PDF
→ отправляет 3 файла подряд в Telegram
```

✅ Выглядит профессионально  
✖ Нельзя отправить более 10 документов за раз, нужно следить за лимитами Telegram API  
✖ Не всегда удобно, если юзер хочет просто посмотреть

---

#### 🔹 **Вариант 3: Автоформируемое сообщение из папки**
Если ты хочешь, чтобы при запросе по ключу `регистрация ООО` бот сам находил нужные документы в Google Диске, то:

   - Формируешь список ссылок
   - Отправляешь пользователю
