## Как подключать сторонние npm-пакеты или писать свои узлы в self-host n8n

> Для этого нужен доступ к файлам сервера и возможность перезапустить n8n.  
> В облачном хостинге (theboxai.store и др.) это недоступно.

| Шаг | Что делаем | Комментарий |
|-----|------------|-------------|
| **1. Создаём папку для расширений** | Например `/home/n8n/custom` | Можно любая, главное потом правильно указать путь |
| **2. Инициализируем package.json** | ```bash<br>cd /home/n8n/custom<br>npm init -y<br>``` | |
| **3. Ставим нужные библиотеки** | ```bash<br>npm install axios lodash …<br>``` | Сюда же можно добавить `npm install n8n-nodes-starter` если пишете собственный узел |
| **4. Экспортируем переменную окружения** | ```bash<br>export N8N_CUSTOM_EXTENSIONS=/home/n8n/custom<br>``` | В docker-compose: `environment: - N8N_CUSTOM_EXTENSIONS=/home/node/.n8n/custom` |
| **5. Перезапускаем n8n** | `docker compose restart n8n` или `systemctl restart n8n` | При старте движок подтянет все зависимости из указанной папки |
| **6. Проверяем** | В редакторе появятся ваши кастомные узлы; в Code-node можно делать `import ...` | |

### Если нужен _только_ пакет внутри Code-node  
1. **Self-host:** добавляете пакет в `N8N_CUSTOM_EXTENSIONS`, как показано выше, и импортируете его в Code-node.  
2. **Облачный n8n:** единственный вариант — без-пакетный код (чистый JS/Python) или обращение к внешнему REST-API, потому что ставить npm-зависимости нельзя.

## 📊 **Может ли бот брать всю историю переписки из Supabase?**

**Да, технически может:**

## 🚩 **В чем могут быть проблемы:**

### 1️⃣ Ограничение по токенам LLM

- У каждой LLM есть ограничение контекста:
  - GPT-4o, Claude 3 Opus — до 100–200k токенов (примерно 50–100 тыс слов)
  - GPT-4-8k / 16k — сильно меньше.
- Если твоя переписка длинная (несколько месяцев общения), ты банально не сможешь всё передать в модель.

#### 👉 Возможный выход:
- Делать **сжатие старых сообщений** (резюме, summary).
- Хранить не всю переписку, а цепочку сжатых итогов + последние полные сообщения.
- Это называется **"резюмерная память"** или **"long-term memory compression"**.

---

### 2️⃣ Время отклика

- Если ты каждый раз будешь тянуть всю историю из базы — это:
  - лишняя нагрузка на БД
  - может замедлять работу
  - долгое формирование промпта.

#### 👉 Выход:
- Хранить отдельную таблицу с "long-term summary" по пользователю.
- Передавать LLM итоговый сжатый контекст + последние 5–10 сообщений.

---

### 3️⃣ Цена

- Чем длиннее промпт — тем дороже вызовы к OpenAI.
- Например, передавать каждый раз по 100k токенов — будет стоить заметно дороже.
