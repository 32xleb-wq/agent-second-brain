## 7. Prepare Prompt (новая логика)

Используем **Function**-нодку:

```js
// items = массив строк из chat_history (role, content)
const msgs = items.map(i => `${i.json.role}: ${i.json.content}`);
return [
  {
    json: {
      prompt: msgs.reverse().join('\n').slice(-4000)   // обрезаем на 4К символов
    }
  }
];
```
