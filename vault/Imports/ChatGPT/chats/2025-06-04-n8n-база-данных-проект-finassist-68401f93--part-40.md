### Что означает `http_request.content is NULL` (точнее `…body_json is NULL`)

* Расширение **supabase_http** возвращает запись `http_request`.  
  Поля (тип 1.6):

  | поле          | тип   | заметка                               |
  |---------------|-------|---------------------------------------|
  | status_code   | int   | 200, 401, 429 …                       |
  | headers       | jsonb | заголовки ответа                      |
  | body          | bytea | «сырое» тело ответа                   |
  | body_json     | jsonb | `NULL`, если тело не JSON или запрос не удался |

* Когда `body_json = NULL`, функция `get_openai_embedding()` пытается
  взять `resp -> 'body_json' -> …`  → NULL → каст в `vector` падает и
  поднимается ошибка «content is NULL».

**Значит сам HTTP-запрос не вернулся с валидным JSON.**  
Чаще всего это:

| status_code | Причина | Что делать |
|-------------|---------|------------|
| **401**     | неверный (`sk-…`) ключ | проверь, что key из OpenAI именно для Embeddings и не отозван |
| **404**     | URL с опечаткой | должен быть `https://api.openai.com/v1/embeddings` |
| **429**     | лимит запросов / нет средств | проверь usage в OpenAI dashboard |
| **500**     | редкая ошибка сервиса | повтори позже |

## Обновлённая функция, которая сразу проверяет `status_code`

```sql
create or replace function get_openai_embedding(txt text)
returns vector(1536)
language plpgsql
stable
as $$
declare
    r http_response;     -- тип записи из supabase_http
    j jsonb;
begin
    r := http_post(
           'https://api.openai.com/v1/embeddings',
           jsonb_build_object(
             'headers', jsonb_build_object(
               'Authorization', 'Bearer sk-ВАШ_КЛЮЧ',
               'Content-Type',  'application/json'
             ),
             'body', jsonb_build_object(
               'model', 'text-embedding-3-small',
               'input', txt
             )
           )
         );

    if r.status_code <> 200 then
        raise exception 'OpenAI error, status %, body %',
            r.status_code,
            convert_from(r.body,'UTF8');
    end if;

    j := r.body_json;
    return (j -> 'data' -> 0 -> 'embedding')::vector;
end;
$$;
```

* Если ключ неправильный / лимит превышен — функция явно бросит ошибку с текстом OpenAI.  
* Если 200 — вернёт корректный `vector`.

```sql
create or replace function get_openai_embedding(txt text)
returns vector(1536)
language plpgsql stable as
$$
declare
  r jsonb;
  j jsonb;
begin
  -- сам HTTP-запрос
  r := http_post(
         'https://api.openai.com/v1/embeddings',
         jsonb_build_object(
           'headers', jsonb_build_object(
               'Authorization', 'Bearer sk-ВАШ_КЛЮЧ',
               'Content-Type',  'application/json'
           ),
           'body', jsonb_build_object(
               'model', 'text-embedding-3-small',
               'input', txt
           )
         )
       );

  -- если статус ≠ 200 → бросаем понятную ошибку
  if (r ->> 'status')::int <> 200 then
     raise exception 'OpenAI error %, body %',
            r ->> 'status',
            r ->> 'body';
  end if;

  j := r -> 'body_json';              -- ответ OpenAI в виде JSON

  return (j -> 'data' -> 0 -> 'embedding')::vector;
end;
$$;
```

## Как увидеть ответ, не вызывая ошибку

```sql
-- 1) забираем JSON-результат целиком …
WITH r AS (
```
