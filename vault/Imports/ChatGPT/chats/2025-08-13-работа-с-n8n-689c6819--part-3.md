## Как включить SSL Let’s Encrypt на Beget
1. **Открой управление доменом** (в списке доменов — кнопка справа).
2. Выбери **«Управление SSL сертификатами»**.
3. Нажми **«Выпустить сертификат Let’s Encrypt»**.
4. Дождись, пока статус сменится на «Активен» (обычно 5–15 мин, но может до часа).
5. После этого домен начнёт открываться по **https://**.

💡 Beget сам продлевает сертификаты каждые 90 дней — ничего вручную делать не нужно.

---

## Обязательно ли включать
Технически:
- Если сайт — просто тест или используется только для тебя, **не обязательно**.
- Если сайт открыт для пользователей, особенно с формами, авторизацией, оплатой — **обязательно**:
  - HTTPS шифрует данные.
  - Браузеры без него помечают сайт как «Небезопасный».
  - Поисковые системы (Google, Яндекс) занижают позиции сайтов без HTTPS.
  - Некоторые API и браузерные функции работают только через HTTPS.

**Replicate** — это облачная платформа, где разработчики могут:

   ```bash
   curl http://localhost:5678
   ```

   Открываем конфиг:
   ```bash
   nano ~/.n8n/.env
   ```

   ```env
   N8N_HOST=n8nforme.fun
   N8N_PORT=5678
   N8N_PROTOCOL=https
   WEBHOOK_URL=https://n8nforme.fun/
   ```
   Сохраняем (`CTRL+O`, потом `Enter`, потом `CTRL+X`).

4. **Настраиваем обратный прокси (чтобы работал HTTPS)**  
   Устанавливаем Nginx:
   ```bash
   apt update && apt install nginx -y
   ```

   ```bash
   nano /etc/nginx/sites-available/n8n
   ```
   Вставляем:
   ```nginx
   server {
       listen 80;
       server_name n8nforme.fun;

       location / {
           proxy_pass http://localhost:5678;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }
   ```
   Сохраняем и включаем сайт:
   ```bash
   ln -s /etc/nginx/sites-available/n8n /etc/nginx/sites-enabled/
   nginx -t
   systemctl restart nginx
   ```

5. **Ставим SSL через Let’s Encrypt**
   ```bash
   apt install certbot python3-certbot-nginx -y
   certbot --nginx -d n8nforme.fun
   ```

6. **Перезапускаем n8n**
   ```bash
   pm2 restart n8n
   ```
