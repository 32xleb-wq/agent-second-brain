- **Small Blocks (Default)**

  • Лимит газа: **3,000,000**  
  • Для лёгких действий: одиночный claim, простой swap, мелкие транзы.

- **Big Blocks**  
  • Время подтверждения: ~1 минута  
  • Лимит газа: **30,000,000**  
  • Для тяжёлых мульти-коллов: **Claim All**, создание LP, голосование, bribe.

### Если всё ещё не проходит
- Сними галочки и **клейми частями** (по одному/двум токенам).  
- Убедись, что есть достаточно нативного газа на сети Hyperliquid.  
- Вернись на Small Blocks для дальнейших быстрых действий.

Это безопасная настройка на уровне сети; на средства не влияет — только на лимит газа и скорость подтверждения.

# Эфир / L2 (Arbitrum, Optimism, Base)

**1) Aave v3** — «синий чип» для классических лупов (ETH↔стейблы, stETH eMode).  
Плюсы: eMode даёт повышенные лимиты внутри «корзины» высококоррелированных активов (например, LST), много аудитов, ликвидность. Минус: более «ванильные» пары. citeturn5search1

**2) Morpho Blue** — изолированные рынки с LLTV (liquidation LTV), минималистичный дизайн рисков.  
Плюсы: каждая пара изолирована → меньше кросс-заражения, чёткие лимиты LLTV. Минус: нужно внимательно выбирать оракул/рынок. citeturn14search18

**3) Euler (Euler Prime / v2)** — изоленные рынки + «risk curators».  
Плюсы: гибкая матрица рисков, хорошие инструменты для мультиплирования под конкретные активы. Недавно перезапущен v2 (Prime). Минус: рынки моложе Aave. citeturn13search6

**4) Gearbox** — леверидж-«кредит-аккаунты» поверх внешних протоколов (делает за вас supply/borrow/LP как стратегию).  
Плюсы: готовые стратегии и интеграции, высокий кап-эффект. Минусы: больше абстракции → внимательно читать риск-доки стратегии. citeturn11search18

**5) Dolomite (Arbitrum)** — маржин-лендинг с изоляцией активов и «looping» как фича.  
Плюсы: удобно лупить нишевые активы под изоляцией. Минусы: ликвидность ниже, чем в Aave. citeturn12open1

**Также по делу:** SparkLend (Maker/DAI), Compound v3 (проверенный базовый лендинг).

## Быстрый чек-лист перед лупом
1) **Тип рынка:** изолированный vs общий пул. Изолированные (Morpho/Euler/Dolomite) безопаснее для экзотики. citeturn14search18  
2) **LLTV/лимиты и ликвидашка:** чем выше LLTV — тем больше плечо, но меньше буфер. (Morpho Blue чётко фиксирует LLTV по рынку.) citeturn14search18  
3) **Оракул:** для нестейблов проверяй источник цены.  
4) **Net borrow APR/APY:** если есть **pair-specific** инсентивы (как в Kamino) — считай реальную стоимость заёма (часто < 0%).  
5) **Утилизация пула:** высокая утилизация = риск скачка ставок.  
6) **Риск-менеджмент:** алерты на HF/LTV, автобаланс/погашение при просадке.
