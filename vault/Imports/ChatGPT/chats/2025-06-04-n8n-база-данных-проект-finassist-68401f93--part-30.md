### Как починить If-ноду, чтобы она **правильно определяла, есть ли пользователь** в таблице `users`

1. **Убедись, что Supabase-нода «проверяем есть ли юзер» возвращает массив `data`**  
   - В Supabase-ноде в «Settings» включи ☑ *Always Output Data*.  
   - На выходе этой ноды структура выглядит так:  

     ```json
     {
       "data": [
         {
           "user_id": 235302653,
           "username": "Theboxal",
           "first_name": "Паша",
           "created_at": "2025-06-19T14:40:00.000Z"
         }
       ],
       "count": 1
     }
     ```
     Если пользователя нет, массив `data` пустой `[]`.

2. **Настрой If-ноду**

   | Поле                             | Что выбрать / написать                                    |
   |---------------------------------|-----------------------------------------------------------|
   | **Field (Left Value)**          | `={{ $json.data.length }}`                                |
   | **Тип**                         | `Number`                                                 |
   | **Condition / Operator**        | `is greater than`                                        |
   | **Right Value**                 | `0`                                                      |
   | **Convert types where required**| выключено (оставь ☐)                                      |

   <br>

   - **True-ветка** (есть пользователь) пойдёт дальше по «существующий юзер».  
   - **False-ветка** (нет пользователя) — создаёшь нового пользователя и спрашиваешь всё, что нужно.

3. **Почему теперь работает**

- `data.length` — это всегда число:  
  - `> 0` → пользователь найден;  
  - `0` → пользователь отсутствует.

