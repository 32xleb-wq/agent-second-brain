## **Цель:**
Сделать бота в **n8n**, который:
- получает сообщения от пользователя,
- сохраняет их в **Supabase** (вместе с ответами),
- при новом сообщении — достаёт всю историю (или её часть),
- подаёт её в prompt вместе с новым сообщением,
- отправляет это в LLM (например, OpenAI),
- сохраняет результат и возвращает его пользователю.

---

## **Структура БД в Supabase:**
Одна таблица `messages`:

| Поле           | Тип             | Описание                            |
|----------------|------------------|-------------------------------------|
| `id`           | uuid             | Уникальный ID (авто)                |
| `user_id`      | text             | ID пользователя                     |
| `role`         | text             | 'user' или 'assistant'              |
| `message`      | text             | Текст сообщения                     |
| `timestamp`    | timestamptz      | Время отправки                      |
| `session_id`   | text             | (опц.) ID сессии                    |

---

## **Структура бота в n8n:**

### **1. Trigger (например, Telegram / Webhook)**
- Получает сообщение от пользователя.
- Извлекает `user_id` и `message`.

### **2. PostgreSQL (SELECT) — Получение истории из Supabase**
- Запрос в Supabase:
```sql
SELECT role, message
FROM messages
WHERE user_id = '{{$json["user_id"]}}'
ORDER BY timestamp DESC
LIMIT 10;
```
- Возвращает последние 10 реплик (или сколько нужно).

### **3. Code Node — Формирование Prompt'а**
- Склеивает историю в формат:
```
User: Привет
Assistant: Привет! Чем могу помочь?
User: Расскажи про витамины
...
User: {{$json["новое сообщение"]}}
```
- Выдаёт строку для отправки в LLM.

### **4. HTTP Request — Запрос в OpenAI**
- Отправляем prompt в OpenAI (или другую LLM).
- Получаем ответ.

### **5. PostgreSQL (INSERT) — Сохраняем новое сообщение и ответ**
- Сохраняем в Supabase:
  - сообщение пользователя (`role = user`)
  - ответ бота (`role = assistant`)

### **6. Ответ пользователю (Telegram / Webhook Response)**

---

## **Как бот "помнит":**
Он **каждый раз** перед ответом достаёт историю из Supabase, подгружает её в prompt и таким образом формирует "контекст". Бесконечная память обеспечена за счёт сохранения всех диалогов в базе.

---

## **Советы:**
- Ограничивай количество сообщений в prompt (например, 10–15), чтобы не выйти за пределы токенов.
- Можно реализовать `session_id` для разделения диалогов по темам.
- Добавь фильтр по дате или длине диалога (например, за последние 7 дней).

Конечно! Давай разберём каждую строку этого кода пошагово:

---

### 🔁 `let messages = $items().map(i => i.json);`

**Что делает:**
- Берёт все входящие элементы (items) в узле `Function`.
- Каждый элемент — это одно сообщение из базы данных Supabase.
- `.map(i => i.json)` — извлекает JSON-данные из каждого элемента.

**Результат:** массив сообщений, например:

```json
[
  { "role": "user", "message": "Привет!" },
  { "role": "assistant", "message": "Привет, чем могу помочь?" },
  ...
]
```

---

### 🔄 `let prompt = messages.reverse().map(m => \`\${m.role === 'user' ? 'User' : 'Assistant'}: \${m.message}\`).join('\n');`

**Что делает:**
- `messages.reverse()` — переворачивает порядок сообщений (самые старые будут первыми).
- `.map(...)` — превращает каждое сообщение в строку вида:
  - `User: Привет!`
  - `Assistant: Привет, чем могу помочь?`
- `join('\n')` — соединяет всё в одну строку, где каждое сообщение — с новой строки.

**Результат (пример):**
```
User: Привет!
Assistant: Привет, чем могу помочь?
User: Расскажи мне про бизнес-планы.
```

---

### ➕ `prompt += \`\nUser: \${$json["message"]["text"]}\`;`

**Что делает:**
- Добавляет в конец prompt текущее сообщение пользователя из Telegram (`$json["message"]["text"]`).
- Это нужно, чтобы GPT понимал, на что нужно ответить.

**Пример (дополнение к прошлому):**
```
User: Привет!
Assistant: Привет, чем могу помочь?
User: Расскажи мне про бизнес-планы.
User: А как выбрать нишу?
```

---

### 📦 `return [{ json: { prompt, user_id: $json["message"]["from"]["id"] } }];`

**Что делает:**
- Возвращает объект с:
  - `prompt` — итоговым диалогом для OpenAI.
  - `user_id` — ID пользователя из Telegram (для сохранения истории в Supabase).

**Результат:**
```json
{
  "prompt": "User: Привет!\nAssistant: Привет!\nUser: А как дела?",
  "user_id": 123456789
}
```
