## Конкретно по скринам

### 1. Верх слишком разный в разных версиях

На одном экране верх компактный, на другом огромный, на третьем есть “фраза дня”, “навигатор”, “ресурс”, “шаги”. Это всё правильно по смыслу, но в текущем виде **верх съедает пол-экрана**.

Нам нужен не лендинг, а рабочий пульт.

Лучше так:

```txt
Сегодня · суббота, 27 июня

Не идеально. Честный следующий шаг.

[День в процессе] [Средняя энергия] [Чек-ин сделан]
```

И всё. Без огромной цитаты на первом экране.

### 2. “Фраза дня” хорошая, но не должна быть такой большой

Блок фразы дня сейчас красивый, но занимает слишком много места. Это второстепенная вещь.

Лучше сделать маленькую строку:

```txt
Фраза дня: Сегодня не нужно победить всю жизнь.
[сменить]
```

Или вообще свернуть её в компактную карточку под верхом.

### 3. “Навигатор дня” сейчас занимает слишком много

Кнопки:

- утренний чек-ин;
- собрать план;
- добавить задачу;
- итог дня;
- SOS.

По смыслу правильно. Но визуально это много.

Я бы сделал не отдельный большой блок, а **одну горизонтальную панель действий**:

```txt
[Чек-ин ✓] [План] [Добавить] [Итог]
```

А SOS отдельно, но маленьким.

### 4. SOS-кнопка сейчас мешает

“Мне плохо” важна, но сейчас она **перекрывает контент**. На нескольких скринах она закрывает карточки, прогресс и кнопки. Это плохой UX.

Надо выбрать один вариант:

**Вариант нормальный:** маленькая кнопка в верхнем блоке:

```txt
[Мне плохо / откат]
```

**Вариант второй:** маленькая floating-кнопка, но круглая/компактная:

```txt
SOS
```

А не большая плашка, которая лежит поверх карточек.

### 5. Выбор энергии слишком крупный

Пять больших карточек “Авария / Низкая / Средняя / Высокая / Отдых” занимают много места.

Лучше chips в одну строку с горизонтальным скроллом:

```txt
Ресурс сейчас:
[Авария] [Низкая] [Средняя] [Высокая] [Отдых]
```

Активная — залитая. Остальные — outline.

### 6. Карточки задач перегружены кнопками

Сейчас в карточке есть:

- микрошаг;
- начать;

- прогресс;
- уровень;
- направление;
- следующий шаг.

Это всё полезно, но для главного экрана многовато.

На главном экране карточка должна быть проще:

```txt
Следующий шаг: открыть книгу и прочитать 1 страницу

```

А “варианты”, “след прогресса”, подробные уровни энергии — внутрь карточки по нажатию.

### 7. Восстановление сейчас выглядит как отдельная страница, но на главном его слишком много

А подробный экран восстановления — отдельная вкладка “Отдых”.

### 8. “Сегодня уже засчитано” хороший блок, но его надо сделать компактнее

То есть это не “дашборд всего”. Это **карта дня**.

## Главная логика первого экрана

Человек открывает приложение утром. У него может быть тревога, ватность, перегруз, стыд, избегание, желание залипнуть. Значит первый экран должен не добавлять хаос, а быстро дать опору.

Он должен ответить на 5 вопросов:

```txt
1. Какой сегодня день?
2. В каком я режиме?
3. Что сегодня главное?
4. Какой самый первый честный шаг?
5. Что делать, если мне плохо или я не вывожу?
```

Всё. Остальное — вторым слоем.

## Главная ошибка текущего экрана

Сейчас экран пытается сразу показать:

- чек-ин;
- фразу дня;
- навигатор;
- выбор энергии;
- задачи;
- восстановление;
- прогресс;
- SOS;
- итоги;
- кнопки;
- проценты;
- вкладки.

Это слишком много для утра.

Утром человеку не нужна вся система. Ему нужна **простая ориентация**.

# Как должна строиться логика первого экрана

Я бы разделил первый экран на 4 смысловых зоны.

## 1. “Где я сейчас?”

Самый верх:

```txt
Сегодня · суббота, 27 июня

Режим: не выбран / низкая энергия / средняя / высокая / отдых / авария
Чек-ин: не сделан / сделан
```

Без огромных цитат. Без красивостей. Просто ориентация.

Если чек-ин не сделан, главный экран должен говорить:

```txt
Сначала выбери состояние. Потом соберём день.
```

Потому что без состояния система не знает, какой план показывать.

## 2. “Что меня сегодня ждёт?”

Вот это главный блок. Не задачи. А **карта дня**.

Например:

```txt
Сегодня тебя ждёт:

1. Минимум дня
Не потерять контакт с собой и сделать один маленький шаг.

2. Главное направление
Здоровье: подготовить анализы.

3. Поддержка / восстановление
10 минут прогулки или чай без телефона.

4. Вечером
Коротко зафиксировать, что было.
```

Это сразу даёт человеку ощущение:  
“Ага, день не бесконечный. Не надо решать всю жизнь. Есть структура.”

## 3. “С чего начать?”

После карты дня должен быть один главный CTA:

```txt
Первый честный шаг:
Открыть список анализов и отметить 3 пункта.

[Начать 10 минут]
[Сделать микрошаг]
```

Не пять карточек. Не десять кнопок. Один вход в день.

Главная задача первого экрана — **снизить порог входа**.

## 4. “А если мне плохо?”

SOS должен быть не плавающей огромной кнопкой, которая мешает, а спокойным аварийным выходом:

```txt
Если тяжело:
[Перейти в аварийный режим]
```

И всё.

Аварийный режим должен менять весь день:

```txt
Сегодня только минимум:
- вода
- еда
- душ / 5 минут без телефона
- одна маленькая заметка
```

То есть SOS — это не просто кнопка. Это переключатель логики дня.
