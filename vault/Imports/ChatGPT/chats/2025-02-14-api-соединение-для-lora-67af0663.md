Для настройки API соединения с CivitAI для модели LoRA на основе [их документации](https://developer.civitai.com/docs/api/public-rest), тебе потребуется выполнить несколько шагов:

### **1. Получение API-ключа**
Зарегистрируйся на [CivitAI](https://civitai.com/) и получи API-ключ. Он понадобится для аутентификации в запросах.

### **2. Установка необходимых инструментов**
Если ты работаешь в Python, установи библиотеку `requests`, если она ещё не установлена:
```bash
pip install requests
```

### **3. Получение списка моделей LoRA**
Используй следующий код, чтобы получить список моделей LoRA:

```python
import requests

API_KEY = "ТВОЙ_API_КЛЮЧ"
headers = {"Authorization": f"Bearer {API_KEY}"}
url = "https://civitai.com/api/v1/models?types=LoRA"

response = requests.get(url, headers=headers)

if response.status_code == 200:
    data = response.json()
    for model in data["items"]:
        print(f"Название: {model['name']}, ID: {model['id']}")
else:
    print("Ошибка:", response.status_code, response.text)
```

### **4. Загрузка конкретной модели LoRA**

### **5. Загрузка файла модели**
```python
model_id = 12345  # Укажи ID модели
url = f"https://civitai.com/api/v1/model-versions/{model_id}"

response = requests.get(url, headers=headers)

if response.status_code == 200:
    model_data = response.json()
    for file in model_data.get("files", []):
        file_url = file["downloadUrl"]
        print(f"Загрузка {file['name']} с {file_url}")

        file_response = requests.get(file_url, headers=headers)
        if file_response.status_code == 200:
            with open(file["name"], "wb") as f:
                f.write(file_response.content)
            print(f"Файл {file['name']} сохранён.")
        else:
            print(f"Ошибка загрузки {file['name']}: {file_response.status_code}")
else:
    print("Ошибка:", response.status_code, response.text)
```

Для настройки API-соединения с моделью LoRA на платформе fal.ai, следуйте следующим шагам:

Установите официальный клиентский пакет `@fal-ai/client`, который предоставляет удобный интерфейс для взаимодействия с API модели.

npm install --save @fal-ai/client

API использует API-ключ для аутентификации. Рекомендуется установить переменную окружения `FAL_KEY` в вашем runtime.

export FAL_KEY="ВАШ_API_КЛЮЧ"

Если вы не можете установить переменные окружения, вы можете настроить API-ключ программно:

fal.config({
  credentials: "ВАШ_API_КЛЮЧ"
});
```

**Важно:** При выполнении кода на стороне клиента (например, в браузере или мобильном приложении) убедитесь, что ваш `FAL_KEY` не подвергается риску утечки. В таких случаях рекомендуется использовать серверный прокси для отправки запросов к API.

```javascript
import { fal } from "@fal-ai/client";

const result = await fal.subscribe("fal-ai/flux-lora-portrait-trainer", {

```

В этом примере `images_data_url` представляет собой данные изображений в формате Base64 или URL-адреса изображений, которые вы хотите использовать для обучения модели.

### 4. Отслеживание статуса запроса

Обучение модели может занять некоторое время. Вы можете отслеживать статус вашего запроса, используя `requestId`, полученный при отправке запроса:

```javascript
import { fal } from "@fal-ai/client";

### ChatGPT — 2025-02-14 10:03

Файл `openapi.json` — это спецификация API в формате OpenAPI 3.1.0 для сервиса **BFL API**.  

Этот API требует аутентификацию с помощью API-ключа (`x-key` в заголовке) и предоставляет несколько эндпоинтов для генерации изображений с использованием модели **FLUX**. Также он поддерживает финетюнинг (дообучение) моделей.  

### **Основные эндпоинты**
1. **Генерация изображений**  
   - `POST /v1/flux-pro-1.1` — Генерация изображения с FLUX 1.1 Pro  
   - `POST /v1/flux-pro-1.0-fill` — Генерация с использованием изображения и маски  
   - `POST /v1/flux-pro-1.0-canny` — Генерация с контрольным изображением Canny  
   - `POST /v1/flux-pro-1.0-depth` — Генерация с контрольным изображением глубины  

2. **Финетюнинг моделей**  
   - `POST /v1/finetune` — Запуск обучения новой модели  
   - `GET /v1/finetune_details` — Получение информации о дообученной модели  
   - `POST /v1/delete_finetune` — Удаление дообученной модели  

3. **Получение результата генерации**  
   - `GET /v1/get_result?id={task_id}`  

---

### **Пример запроса для генерации изображения (Python)**
```python
import requests

API_KEY = "ТВОЙ_API_КЛЮЧ"
url = "https://api.bfl.com/v1/flux-pro-1.1"
headers = {"x-key": API_KEY, "Content-Type": "application/json"}

payload = {
    "prompt": "Фантастический город будущего",
    "width": 1024,
    "height": 768,
    "steps": 40,
    "seed": 42,
    "output_format": "jpeg"
}

response = requests.post(url, json=payload, headers=headers)

if response.status_code == 200:
    task = response.json()
    print("ID задачи:", task["id"])
    print("URL для проверки статуса:", task["polling_url"])
else:
    print("Ошибка:", response.status_code, response.text)
```
