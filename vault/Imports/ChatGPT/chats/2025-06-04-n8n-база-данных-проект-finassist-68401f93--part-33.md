## 1  Сохранить `id` документа, который только что создали

1. В **Supabase → Create a row** включите **“Return Fields”** → выберите только колонку `id`.  
   n8n вернёт, например:
   ```json
   {
     "id": "e7c6e4d5-…-a9b1"
   }
   ```

2. Сразу за этой нодой поставьте **Set → “Store Doc ID”**  
   ```yaml
   new field:  document_id   = {{ $json.id }}
   new field:  doc_text      = {{ $json.content }}    # полный извлечённый текст
   ```

Таким образом `document_id` и текст пойдут дальше по цепочке.

   *Table*: `user_documents`

   *Fields*:  
   | Column   | Value                                |
   |----------|--------------------------------------|
   | summary  | `={{ $json.summary }}`               |

## 3  Создать embedding и занести в таблицу `embeddings`

2. **Supabase → Create row**  
   *Table*: `embeddings`  
   | Column       | Value                                       |

   | document_id  | `={{ $json.document_id }}`                  |
   | content      | `={{ $json.doc_text }}`                     |

> **Параметр “Embedding”**: укажите *Vector* ( type = vector(1536) )
