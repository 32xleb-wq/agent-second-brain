В **Make.com** можно автоматически конвертировать изображения из **WEBP в JPG** с помощью модуля **"Image" → "Convert an image"**. Вот пошаговая инструкция:  

### **Шаги для конвертации WEBP в JPG**  

1. **Добавьте триггер**  
   – Например, модуль **"HTTP" → "Get a file"**, если изображение приходит по URL,  
   – Или **"Google Drive" / "Dropbox" → "Watch files"**, если файл загружается в облако.  

2. **Добавьте модуль "Image" → "Convert an image"**  
   – В поле **"Source file"** вставьте выходные данные из предыдущего шага (ссылку или файл).  
   – В поле **"Target format"** выберите **JPG**.  

3. **Сохраните или отправьте JPG-файл**  
   – Используйте **"Google Drive → Upload a file"**, чтобы сохранить в облаке.  
   – Или **"Email → Send an email"**, чтобы отправить по почте.  

### **Дополнительно**  
Если вам нужно изменить размер изображения при конвертации, можно добавить модуль **"Resize an image"** перед сохранением.  

Попробуйте этот сценарий, и если возникнут вопросы — спрашивайте!

WordPress поддерживает **WEBP** начиная с версии **5.8**, но иногда могут быть проблемы с загрузкой. Возможные причины:  

### **1. Хостинг не поддерживает WEBP**  
Некоторые серверы не настроены на работу с WEBP. Проверьте **файл .htaccess** или спросите поддержку хостинга.  

### **2. Ограничения MIME-типа**  
WordPress может блокировать WEBP из-за **неразрешенного MIME-типа**. Попробуйте добавить этот код в `functions.php`:  

```php
function allow_webp_upload($mime_types) {
    $mime_types['webp'] = 'image/webp';
    return $mime_types;
}
add_filter('upload_mimes', 'allow_webp_upload');
```

### **3. Плагины или темы блокируют WEBP**  
Некоторые плагины кеширования или безопасности могут блокировать загрузку WEBP. Проверьте **деактивировав плагины** и попробовав снова.  

### **4. Ошибки в настройках медиа**  
Если используется **плагин для изображений (например, Smush или EWWW Image Optimizer)**, проверьте его настройки — может быть отключена поддержка WEBP.  

### **5. Браузер или версия PHP устарели**  
Проверьте, что ваш сервер работает на **PHP 7.4+** и вы используете современный браузер.  

Если WordPress не принимает WEBP, можно **автоматически конвертировать их в JPG** перед загрузкой, например, с помощью **Make.com**. Хотите инструкцию?
