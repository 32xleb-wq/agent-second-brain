### 🔧 Шаги для парсинга `.docx` в обычный текст:

#### 1. **HTTP Request**

- Обязательно установите **Response Format: File**.

#### 2. **Function Node (перевод бинарного в base64)**
```javascript
// Преобразует бинарный .docx в base64 строку
return [
  {
    json: {
      base64Docx: $binary.data.data
    }
  }
];
```

#### 3. **Code Node (Node.js)** с `mammoth` (установите модуль)
Если вы используете Self-Hosted n8n, установите модуль:
```bash
npm install mammoth
```

В Node.js коде:
```javascript
// Распарсить .docx из base64 с помощью библиотеки mammoth
const mammoth = require("mammoth");

const buffer = Buffer.from($json.base64Docx, 'base64');

return mammoth.extractRawText({ buffer })
  .then(result => {
    return { json: { text: result.value } };
  })
  .catch(error => {
    return { json: { error: error.message } };
  });
```
