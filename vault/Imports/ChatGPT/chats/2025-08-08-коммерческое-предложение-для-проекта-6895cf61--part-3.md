## 4 самых частых причины и как исправить

| № | Причина | Как проверить | Как починить |
|---|---------|--------------|--------------|
| **1** | Используете **Service Account**, но таблица не «поделена» с его e-mail | В Credentials → внутри ключа JSON есть поле `client_email`. | Откройте таблицу в Google Sheets → **Share** → добавьте этот адрес с правом **Editor**. |
| **2** | OAuth-учётка авторизована только на чтение | В Credentials (n8n) выбраны малые scopes. | Откройте Credential → **Edit** → выставьте Scopes `…/drive`, `…/drive.file`, `…/spreadsheets`, сохраните, нажмите **Reconnect**. |
| **3** | Таблица лежит в **Shared Drive** (ранее «Team Drive») | URL начинается на `/spreadsheets/d/<ID>/edit…`, но в Drive ID указано shared-ID. | В настройках узла включите «Use Shared Drive» и поставьте правильный **Drive ID** или перенесите файл в My Drive. |
| **4** | Spreadsheet ID/Sheet Name ошибочный | ID скопирован не полностью, лист переименовали. | Проверьте параметры узла: • `Spreadsheet ID` = символы между `/d/` и `/edit` • `Sheet Name` = актуальное название вкладки. |

## Быстрый чек-лист

1. **Узнать, каким Credential пользуется узел**   
   ▸ кликните `Append row in sheet` → *Parameters* → поле **Credentials**.

2. **Если Service Account**   
   * В Google Cloud Console → IAM → найдите этот S-account, убедитесь, что активен.  
   * В Google Sheets файле нажмите **Share** → впишите `…@….iam.gserviceaccount.com` → Editor.

3. **Если OAuth2 (личный аккаунт)**   
   * В n8n → *Credentials* → откройте запись → *Reconnect OAuth2 Flow*.  
   * В диалоге Google обязательно отметьте чекбокс **drive**/**drive.file**/**spreadsheets**.  
   * После авторизации запустите узел заново (▶︎ *Execute Node*).

4. **Shared Drive?**   
   * В узле включите **Use Shared Drive** и вставьте ID диска (в URL `folders/<driveId>`).  
   * Либо переместите таблицу в «Мой диск».

| Типичная причина | Как выглядит | Как исправить |

| В твоём теле | Как ждёт HeyGen | Исправляем |
|--------------|-----------------|-----------|

## 2 — Как правильно вставлять выражения n8n

В режиме **Using JSON** выражения должны быть **без кавычек** — тогда n8n подставит готовое значение и результат останется корректным JSON.

```json
"avatar_id": {{$json["avatar_id"]}}
```

Если оставить кавычки `"{{ $json.avatar_id }}"`, в API улетит строка буквально `{{ $json.avatar_id }}`, а не значение.
