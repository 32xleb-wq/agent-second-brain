## 1. Назначение бота
- Telegram-бот для ИП/ООО: консультирует по регистрации, бухучёту и юр-вопросам  
- Работает на GPT-4(o) mini + LangChain-Agent  
- Использует **RAG** (документы в Supabase → pgvector) и поиск Perplexity  
- Держит краткую «память» в Postgres (`memory`), полную историю — в Supabase (`chat_history`)  
- Всегда обращается к пользователю **по имени**, которое сначала запрашивает и пишет в таблицу `users`

## 2. База данных (Postgres + Supabase)

```sql
-- расширения
CREATE EXTENSION IF NOT EXISTS vector;       -- pgvector
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";  -- uuid_generate_v4
CREATE EXTENSION IF NOT EXISTS "pgcrypto";   -- функции времени/crypto

-- пользователи
CREATE TABLE IF NOT EXISTS users (
    user_id     BIGINT PRIMARY KEY,
    username    TEXT,
    first_name  TEXT,
    created_at  TIMESTAMP DEFAULT NOW()
);

-- вся переписка
CREATE TABLE IF NOT EXISTS chat_history (
    id         UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    session_id TEXT,
    user_id    BIGINT REFERENCES users(user_id),
    username   TEXT,
    role       TEXT,
    content    TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

-- «память» для LLM (последние 100 сообщений)
CREATE TABLE IF NOT EXISTS memory (
    id         UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    session_id TEXT,
    role       TEXT,
    content    TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

-- документы + pgvector-RAG
CREATE TABLE IF NOT EXISTS documents (
    id         UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id    BIGINT REFERENCES users(user_id),
    file_name  TEXT,
    file_type  TEXT,
    file_url   TEXT,
    uploaded_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS embeddings (
    id         UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    document_id UUID REFERENCES documents(id),
    content    TEXT,
    embedding  VECTOR(1536),
    created_at TIMESTAMP DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_embeddings_vector
  ON embeddings USING ivfflat (embedding vector_l2_ops);
```

## 3. Telegram-workflow (n8n)

### 3.1 Общая схема
```
Telegram Trigger (один!)
      │
Switch message type (text / voice / ...)
      │
      └─text─►   Supabase GET users (id=from.id)
                   │
                   ▼
                IF (rows==0?)
          ┌────────┴────────┐
          │                 │
        TRUE              FALSE
   (пользователя нет)  (пользователь есть)
          │                 │
Telegram: «Как тебя зовут?» │
Catch next text            │
Upsert users               │
          ▼                 │
      Insert chat_history (role=user)
          ▼
  Prepare Prompt (last ≤100 msgs)
          ▼
      LangChain Agent
          ▼
Insert chat_history (role=assistant)
          ▼
   Telegram Send answer
```

### 3.2 Ключевые узлы

| Нода | Настройка / пояснение |
|------|-----------------------|
| **Telegram Trigger** | `Updates: *`; в workflow только ОДИН триггер |
| **Switch** | Порт 0 → текст (`{{ !!$json.message.text }}`) |
| **GET users** | `Table: users`, `user_id = {{ $json.message.from.id }}` |
| **IF** | `{{ $items(0).length === 0 }}` |
| **Telegram “Как тебя зовут?”** | обычный **Send Message** (а не *Send and Wait*!) |
| **Catch Name (Set)** | берёт ближайший `message.text`, записывает `first_name = trim()` |
| **Upsert users** | `conflict column: user_id` — избавились от ошибки duplicate PK |
| **Insert chat_history** | для юзера и позже для ассистента |
| **Prepare Prompt (Function)** | ```js
const msgs = items.map(i => `${i.json.role}: ${i.json.content}`);
return [{json:{prompt: msgs.reverse().join('\n').slice(-4000)}}];
``` |
| **Agent System prompt** | см. п. 4 |

## 5. Причины прежних ошибок и как мы их устранили

| Ошибка | Решение |
|--------|---------|
| **Duplicate PK** при вставке в `users` | перешли на `operation: upsert`, конфликт-колонка `user_id` |
| **Wait for Response** не ловил ответ | отказались от него; ловим следующее текст-сообщение тем же `user_id` |
| `date/time field value out of range` | конвертируем UNIX-timestamp → ISO-строку: `new Date(date*1000).toISOString()` |
| Supabase **update** требовал «Select Condition» | в режиме *Update* задаём условие: `user_id equals {{ id }}` |
