## 🔧 1. **Архитектурные подходы**

### ✅ **A. Главный агент (Dispatcher) + Исполнители**
- **Описание:** один бот — главный (Router/Dispatcher), он принимает запрос, анализирует его, направляет другим агентам.
- **Плюсы:** централизованный контроль, легко масштабировать исполнителей.
- **Минусы:** одна точка отказа — если "главный" бот упадёт, остальное встанет.

### ✅ **B. Параллельные агенты с общей очередью**
- **Описание:** все боты подписаны на очередь (например, RabbitMQ, Redis Streams или Pub/Sub). Главный бот не нужен — агенты сами забирают релевантные задачи.
- **Плюсы:** децентрализация, высокая отказоустойчивость.
- **Минусы:** сложнее дебажить и координировать поведение.

### ✅ **C. Модель "передачи baton'а" (Chain of Agents)**
- **Описание:** агенты последовательно обрабатывают один и тот же запрос, добавляя к нему результат. Передают друг другу baton.
- **Плюсы:** каждый агент знает только свою часть работы — модульность, легко дебажить.
- **Минусы:** низкая скорость, невозможность параллельной обработки.

## 🧠 2. **Общая память / база знаний**

### Рекомендованные варианты:
- **PostgreSQL + pgvector** — для хранения историй, embeddings, состояний, ответов.
- **Supabase** — отличное готовое решение с REST и WebSocket API.
- **Redis** — для оперативной памяти (временное состояние с TTL).

## 🔁 4. **Параллельно или последовательно?**

### Когда **параллельно**:
- Если задачи независимы (обработка отдельных частей PDF, асинхронные запросы)
- Если важна скорость

### Когда **последовательно**:
- Когда результат одного агента нужен следующему (например, bot 1 парсит, bot 2 анализирует)

Можно и **смешанную модель**:
1. Главный агент получает запрос
2. Распараллеливает задачи нескольким агентам
3. Собирает результат
4. Возвращает ответ

```python
app = FastAPI()
```

## 📑 Пример агента документа

```python
# doc_parser/main.py
from fastapi import FastAPI, UploadFile
import fitz  # PyMuPDF

app = FastAPI()

@app.post("/parse")
async def parse(file: UploadFile):
    content = await file.read()
    with open("temp.pdf", "wb") as f:
        f.write(content)

    doc = fitz.open("temp.pdf")
    text = "\n".join([page.get_text() for page in doc])

    return {"text": text}
```

```sql
CREATE TABLE sessions (
```
