#### ✅ Вариант 1: Указать поле `key` и `value` вручную

1. В настройках Simple Memory:
   - **Key**:  
     ```
     {{$('Telegram Trigger').item.json.message.from.id}}
     ```
   - **Define below**: Включите (ON)
   - Внутри `Define below`, добавьте вручную ключи, которые вы хотите запомнить, например:
     ```json
     {
       "first_name": "{{$json[\"message\"][\"from\"][\"first_name\"]}}"
     }
     ```

#### ✅ Вариант 2: Использовать **Set Node** перед Simple Memory

Если вы не хотите вручную настраивать, тогда просто **вставьте Set узел перед Simple Memory**, и выберите только то, что нужно сохранить.

**Пример:**

1. Добавьте узел **Set** перед Simple Memory
2. Включите **"Keep Only Set"** = `true`
3. Установите, например:
   - `first_name` = `{{$json["message"]["from"]["first_name"]}}`
   - `id` = `{{$json["message"]["from"]["id"]}}`

4. В Simple Memory:
   - Key: `{{$json["id"]}}`
   - Define below: Выключено (OFF)

Теперь узел Simple Memory получит только 2 поля (`first_name`, `id`) и будет работать без ошибок.

Спасибо за фото. Ошибка в настройке подключения к Zep API такая:

> **"Couldn't connect with these settings – ECONNREFUSED"**

Это значит, что n8n **не может подключиться к адресу, указанному в поле API URL**, потому что:

### ⚠️ Причина: `http://localhost:8000`
Ты указал `http://localhost:8000`, но **n8n работает в контейнере (например, Docker)** или на сервере — а **`localhost` в этом случае указывает на сам n8n**, а не на Zep API.

---

### ✅ Решение:

#### 1. **Если Zep API работает локально на твоем компьютере (не в Docker):**
Ты должен указать **IP-адрес машины**, а не `localhost`.

- Открой терминал и выполни:
  ```bash
  ipconfig  # (на Windows)
  ifconfig  # (на Mac или Linux)
  ```
- Найди свой локальный IP, например: `192.168.0.105`
- Замени URL:
  ```
  http://192.168.0.105:8000
  ```

#### 2. **Если n8n и Zep API работают в Docker:**
Они должны быть в одной **Docker-сети**, и ты должен использовать имя сервиса, а не `localhost`.

Например:
```yaml
services:
  n8n:
    ...
  zep:
    image: ...
    ports:
      - "8000:8000"
```

Тогда в n8n укажи:
```
http://zep:8000
```

#### 3. **Если Zep работает на другом сервере:**
Укажи внешний IP или домен, например:
```
https://api.yourdomain.com
```

---

### ❗Важно:
После замены `localhost` убедись, что:
- Порт 8000 **открыт**
- Между машинами есть **сеть**
- Сервер с Zep **работает и отвечает** (можно проверить через браузер)
