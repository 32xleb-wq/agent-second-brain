**Motorhead Memory** – это **опция хранения данных для AI и чат-ботов**, которая используется в `n8n` для управления **контекстом диалогов** в интеграциях с LLM (Large Language Models), такими как ChatGPT, Claude, Gemini и другими.  

Она позволяет **сохранять историю разговоров**, чтобы AI мог "помнить" предыдущие сообщения и поддерживать связную беседу.

---

## 🔹 **Как работает Motorhead Memory?**
Motorhead – это **внешний сервис**, который `n8n` использует как **хранилище контекста** для диалогов с нейросетями.  

📌 **Принцип работы:**  
1. **n8n отправляет данные в Motorhead**, когда пользователь взаимодействует с AI.  
2. **Motorhead сохраняет контекст чата** (например, последние 10 сообщений).  
3. При новом запросе n8n **подгружает из Motorhead предыдущие сообщения**, чтобы AI мог ответить осмысленно.  

---

## 🔹 **Где используется?**  
Motorhead Memory используется в `n8n` в **GPT Nodes**, а также в кастомных чат-ботах, работающих через OpenAI API или другие модели.  

📌 **Применение:**  
- **Чат-боты** (WhatsApp, Telegram, Slack)  
- **Голосовые ассистенты**  
- **Автоответчики** в CRM  
- **AI-поддержка клиентов**

1️⃣ Перейдите в **Chat Model Node** (например, OpenAI GPT-4).

3️⃣ Укажите параметры хранения (например, сколько сообщений хранить).  
4️⃣ Сохраните и протестируйте.

✅ **Поддержка долгих диалогов**
