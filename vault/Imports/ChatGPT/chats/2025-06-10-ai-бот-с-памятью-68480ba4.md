### Используемые блоки:

## 🧠 Что конкретно нужно реализовать:

### 1. **Создание базы знаний:**
Ты можешь использовать:
- **Google Drive/Dropbox/S3** — если файлы хранятся там.
- Или встроенный **n8n Data Store** / простые JSON файлы с вопросами и ответами.

Формат данных может быть такой:

```json
[
  {
    "category": "Контракт",
    "question": "Как составить договор аренды?",
    "template": "В договоре аренды должны быть пункты о сроке, сумме, ответственности и т.д..."
  },
  {
    "category": "Справка",
    "question": "Как оформить справку о доходах?",
    "template": "Вот структура справки о доходах: 1. ФИО, 2. Сумма, 3. Период, 4. Подпись."
  }
]
```

Ты можешь хранить это:
- В **Set Node** (если статично).
- В **HTTP Request** к внешней базе или Google Sheet.
- Или в **n8n Data Store** (локальная NoSQL база).

---

### 2. **Обращение к базе знаний:**
Добавь перед AI Agent блок, который:
- Получает входной вопрос пользователя.
- Сравнивает его с базой (через simple `.find()`).
- Находит **подходящий шаблон**.
- Отправляет шаблон в prompt AI.

Пример в Function Node:

```javascript
// IIFE: ищем похожий вопрос в базе
{{(() => {
  const input = $json.message.toLowerCase();
  const docs = $('Templates').items[0].json.templates;
  const found = docs.find(doc => input.includes(doc.question.toLowerCase()));
  return found ? found.template : "Не найден шаблон. Ответь как можешь.";
})()}}
```

---

### 3. **Контекстная память (Simple Memory):**
Используй `Simple Memory` перед AI Agent:
- Включи флаг `Append last N messages` или `All messages`.
- Таким образом, AI будет помнить предыдущий диалог.

---

### 4. **Формирование запроса для AI:**
Через `Set Node` или `Function Node` собери prompt вида:

```text
Ты — юридический помощник. Используй шаблоны и контекст для точного ответа.

Вопрос: {{ $json.message }}

Контекст: {{ $json.template }}

История общения:
{{ $('Simple Memory').json.messages }}
```

### 🔹 Шаг 2: Найти нужный шаблон по вопросу пользователя

После того как пользователь пишет в Telegram →  
1. Получаешь текст вопроса.
2. Сравниваешь его со всеми строками в таблице (ищешь подходящий шаблон).

📍 **Добавь узел "Function"** после чтения CSV, с таким кодом:

```javascript
// Получаем сообщение пользователя
const userMessage = $json.message.toLowerCase();

// Получаем строки из таблицы
const rows = items;

// Ищем шаблон, который содержит похожий вопрос
const found = rows.find(row =>
  userMessage.includes(row.json.question.toLowerCase())
);

// Если найден, добавляем шаблон в результат
return [
  {
    json: {
      template: found ? found.json.answer_template : "Нет подходящего шаблона.",
      question: userMessage
    }
  }
];
```
