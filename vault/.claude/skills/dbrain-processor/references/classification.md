# Entry Classification

12 октября 2026: классификация переведена с общих категорий (idea/reflection/project/learning)
на 11 тем личной базы (см. [ABOUT.md](about.md) и `vault/MEMORY.md` для контекста пользователя).
Каждая содержательная запись получает ОДНУ основную тему и дописывается в соответствующий
файл `02 Суть/{Тема}.md` — не создаётся отдельный файл в `thoughts/` под каждую мысль.

Эзотерика (самопознание) сохраняется как интерпретация, не как факт. Здоровье — приоритетная тема:
если запись одновременно про здоровье и что-то ещё (например, вес в контент-брифинге) — основной тег
`здоровье`, дополнительный тег второй темы при необходимости.

## Decision Tree

```
Entry text contains...
│
├─ Анализы/УЗИ/гормоны/вес/самочувствие? ──────────> здоровье
├─ Позиционирование/бренд/аудитория блога? ────────> блог
├─ Сценарий/хук/раскадровка ролика? ────────────────> сценарии
├─ Камера/свет/звук/монтаж? ─────────────────────────> съёмка
├─ DeFi/позиция/кошелёк/биржа? ──────────────────────> финансы
├─ Obsidian/бот/автоматизация своей системы? ────────> личная-платформа
├─ БАДы-бизнес/поставщик/направление заработка? ─────> бизнес
├─ Смысл/ценности/философия? ────────────────────────> размышления
├─ Дизайн человека/матрица/астрология/ба-цзы? ───────> самопознание
├─ Замысел на будущее без контент/DeFi/здоровье фокуса? → идеи
└─ Привычка/трекер/расписание/бытовое? ──────────────> дневник
```

Если запись — просто задача с дедлайном (follow-up, напоминание) — это TASK, не тема; остаётся в
daily/ как чеклист, в 02 Суть не идёт.

## Apply Decision Filters

Перед сохранением спроси:
- Это двигает здоровье/блог/DeFi вперёд, или просто фоновая заметка?
- Это противоречит уже записанному в этой теме, или дополняет?
- Нужен ли отдельный полный источник в `03 Переписка`, или достаточно ссылки на `daily/YYYY-MM-DD`?

---

## Photo Entries

Для `[photo]`:

1. Проанализировать содержимое через vision
2. Определить тему по содержимому (скрин анализа → здоровье; кадр съёмки → съёмка; скрин DeFi-дэшборда → финансы)
3. Добавить описание в daily-файл; если содержательно — короткую строку в соответствующий `02 Суть`

---

## Output: как дописывать в 02 Суть

Не создавай новый файл — открой `02 Суть/{Тема}.md`, найди (или создай, если это первое событие
после 12.10.2026) раздел `## Текущий период` в конце файла и ДОПОЛНИ его одним абзацем:

```markdown
**{DD.MM}:** {Короткая суть на 1-3 предложения, с атрибуцией: твои слова vs догадка модели}.
Источник: [[daily/{YYYY-MM-DD}|{DD.MM}]].
```

Не пересказывай весь день — только то, что реально меняет картину темы (новое решение, новый
показатель, завершённое действие, смена позиции). Разговорные/бытовые реплики без содержательного
сдвига в daily/ остаются и в 02 Суть не копируются.

Если мысль достаточно самостоятельна и объёмна (черновик сценария, структурированный план) —
создай для неё отдельный файл в `03 Переписка/{тематическая подпапка}/` и сошлись на него из 02 Суть
так же, как сделано для пробного периода 28.09–12.10.2026 (см. `03 Переписка/08 Пробная версия Клода
(28.09-12.10.2026)/`) — но это исключение, не правило по умолчанию.

## Anti-Patterns (ИЗБЕГАТЬ)

- Копировать весь daily в 02 Суть построчно — только значимые сдвиги
- Придумывать показатели/даты, которых нет в исходном сообщении
- Выдавать предложение модели за подтверждённое решение пользователя
- Создавать новый тег под каждую мысль — только 11 существующих тем
